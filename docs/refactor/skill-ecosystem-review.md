# Skill 生态审查处理记录

审查范围：应用、网站、发布服务三个 PR。外部 Grok 审查针对各自给定的提交；修复后的行为由相邻回归与真实浏览器路径复验，不把作者自测等同于独立批准。

## 应用审查

Grok 对 `9f3f1eed` 相对 `2fe23111` 的审查发现三项问题，均已处理：

- 旧版本回滚仍可能展示新版本的名称。数据库 v18 保存每个版本的市场元信息，安装、离线读取、私人改写和回滚均保留来源与许可。元信息不改变原始包字节及内容摘要。
- 开始独立任务超时后，UI 重试可能生成第二个请求。请求在发送前保存在按用户、画布、会话区分的 sessionStorage 中，重试与刷新页面复用原标识；服务端未完成的 reset 通过恢复操作继续。
- 画布助手可读取同一所有者在技能页创建的投稿。模型查询现在必须严格匹配当前画布，技能页投稿不通过此工具暴露。

本地交叉检查另修复以下问题：

- 市场授权、上传、送审接口不进入外部业务工具目录；真实外部客户端直接请求亦拒绝。
- 网页改稿后清除旧确认，重新获取云端文件、逐项摘要、正文、元信息及预览。初次上传也通过同一校验，避免确认内容与实际稿件不同。重新读取不会覆盖云端稿件或自动送审。
- 安装与修改立即清除技能列表缓存；发布标识允许正式版本号中的点；内容相同而公开元信息不同的发行版仍独立保存。
